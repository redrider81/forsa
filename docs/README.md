# Dokumentation

Underlagen i den här mappen skrevs innan varumärkesbytet och använder det
tidigare namnet **Forsa**. De behålls som referensmaterial för tonalitet och
copy. Det gällande varumärket är **CVB Coaching**.

| Fil | Innehåll |
| --- | --- |
| `project-brief.md` | Positionering, målgrupp och tonalitet |
| `copy-style-guide.md` | Skrivregler |
| `homepage-copy.md` | Copyunderlag för startsidan |
| `executive-coaching-copy.md` | Copyunderlag för executive coaching |
| `forsa-reference-audit.md` | Referensgranskning av tidigare version |

Teknisk dokumentation för portalen, AI-integrationen och environment variables
finns i projektets `README.md`.
